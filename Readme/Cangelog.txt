🎯 Ringkasan Migrasi
Proyek berhasil dimigrasi dari Next.js (App Router) + Serverless Functions menjadi Vite + React Router (SPA murni). Tujuan utama: menghindari biaya serverless functions di Vercel, meningkatkan kecepatan build, dan menyederhanakan arsitektur.

🔧 Konfigurasi
vite.config.js
javascript
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import path from 'path';

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { '@': path.resolve(__dirname, './src') },
    extensions: ['.js', '.jsx', '.ts', '.tsx', '.json'],
  },
  server: { port: 3000, open: true },
  build: {
    outDir: 'dist',
    rollupOptions: {
      output: {
        manualChunks(id) {
          if (id.includes('node_modules') && 
              (id.includes('react') || id.includes('react-dom') || 
               id.includes('react-router-dom') || id.includes('scheduler'))) {
            return 'vendor';
          }
        },
      },
    },
  },
});

🔄 Perubahan Kode Penting
1. Import Path
Semua import ../../lib/... → @/lib/... (menggunakan alias)

File .jsx kini di-import tanpa ekstensi (berkat resolve.extensions)

2. Environment Variables
process.env.NEXT_PUBLIC_* → import.meta.env.VITE_*

Hanya variabel dengan prefix VITE_ yang diekspos ke browser

3. 'use client' Dihapus
Vite tidak mengenali 'use client', semua komponen berjalan di client.

4. Routing
Next.js App Router (/dashboard/page.js) → React Router (<Route path="/dashboard" element={<Dashboard />} />)

5. Layout
src/app/layout.js (dengan <html>, <head>, <body>) → src/components/Layout.jsx (hanya Provider dan wrapper)

6. Metadata
export const metadata di Next.js → dipindahkan ke tag <head> di index.html
