5. LANGKAH DEPLOY (UNTUK DEVELOPER)
Copy semua kode yang sudah diberikan ke file masing-masing di folder WOS-Web/src/.

Pastikan file src/lib/supabase-browser.js sudah memiliki fungsi RPC yang dipanggil (jika belum, tambahkan):

javascript
export const supabase = createClient(import.meta.env.VITE_SUPABASE_URL, import.meta.env.VITE_SUPABASE_ANON_KEY);
// RPC wrapper
export const rpc = (fn, params) => supabase.rpc(fn, params);
Test lokal: npm run dev → buka http://localhost:3000.

Build: npm run build.

Deploy ke Vercel: vercel --prod (atau push ke branch migrasi-vite dan Vercel akan auto-deploy).
